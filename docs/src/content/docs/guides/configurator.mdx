Pick the options for an embed and copy the snippet into your page. The embed beside the form has the same settings and updates as you change them; the Look settings change only the embed, while the configurator keeps these docs' theme. Every option is described in the [embed reference](/reference/embed-api/); for how to use the element and the iframe, see [Embedding](/guides/embedding/).
