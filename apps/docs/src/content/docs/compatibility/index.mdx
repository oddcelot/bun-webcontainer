**Can you run Bun in the browser?** Yes, most of it. [runbun.dev](https://runbun.dev/) runs Bun projects in a browser tab: Bun's transpiler, module resolver, bundler, formatter and semver are Bun's own Rust crates compiled to WebAssembly, and the `Bun.*`, `bun:*` and `node:*` APIs are JavaScript shims that run in the browser's engine. `Bun.serve` apps, `bun install`, `bun:sqlite` and frameworks like Elysia, Hono and Vite work. What a browser can't do (start processes, open raw sockets, load native addons) is missing.

The playground is built from Bun {BUN_VERSION}; `Bun.version` reports <code>{BUN_VERSION}-browser</code>. The date this page last changed is at the bottom.

## At a glance

| Area | Status | In short |
|---|---|---|
| [`Bun.serve`](/compatibility/bun/#bunserve) | 🟡 Partial | `fetch`, `routes`, HTML imports, WebSockets with pub/sub, streaming, cookies, the `error` handler, `maxRequestBodySize` and `requestIP` work. No TLS or timeouts. |
| [`Bun.file`, `Bun.write`](/compatibility/bun/) | 🟡 Partial | Read and write files in the project; no file descriptors. |
| [`Bun.build`](/compatibility/bun/) | 🟡 Partial | Bun's real bundler, as WebAssembly, with plugins (`onResolve`, `onLoad`, `onStart`, `onEnd`). |
| [`Bun.password`, `Bun.CryptoHasher`, `Bun.Glob`, `Bun.semver`](/compatibility/bun/) | ✅ Works | Also `Bun.FileSystemRouter`, `Bun.YAML`, `Bun.TOML`, `Bun.JSONC`, `Bun.JSON5`, `Bun.JSONL`, `Bun.XML`, `Bun.markdown` and `Bun.CookieMap`. |
| [`HTMLRewriter`](/compatibility/bun/) | 🟡 Partial | Bun's `lol-html` as wasm: selectors, element, text, comment, doctype and document-end handlers. Async handlers need a `Response` input. |
| [`bun:sqlite`](/compatibility/bun/) | 🟡 Partial | Built on sql.js; databases, prepared statements and transactions work. |
| [`bun:test`](/compatibility/bun/#buntest) | 🟡 Partial | `bun test` in the console. |
| [`Bun.$`, `Bun.spawn`](/compatibility/bun/) | 🟡 Partial | Bun's shell and its builtins (`ls`, `cat`, `mkdir`, `rm`…) over the project's files. Child processes run `bun`, `node`, `package.json` scripts and installed bins, each in a worker of its own; `spawnSync` only on cross-origin isolated pages. |
| [`Bun.S3Client`, `Bun.s3`](/compatibility/bun/) | 🟡 Partial | S3, R2 and MinIO over `fetch` with Bun's SigV4 signing, presigned URLs and multipart uploads; the bucket needs CORS rules for the page's origin. |
| [`Bun.sql`](/compatibility/bun/) | 🟡 Partial | Postgres on PGlite, in the tab; any `postgres://` URL names a database in the browser. |
| [`Bun.connect`, `Bun.redis`, `bun:ffi`](/compatibility/bun/) | ❌ Missing | No raw sockets or native code in a browser. |
| [`node:*` built-ins](/compatibility/node/) | 🟡 Partial | `buffer`, `events`, `path`, `stream`, `url` and `timers` work; `fs`, `http` and `crypto` mostly do. `child_process` runs child processes; `net` and `tls` are stubs. |
| [Transpiler](/compatibility/toolchain/#transpiler) | ✅ Works | TypeScript, JSX and decorators, with Bun's defaults and the project's `tsconfig.json`. |
| [`bun install`](/compatibility/toolchain/) | 🟡 Partial | Installs from npm, GitHub, `file:` folders and tarballs and `link:`; reads and writes `bun.lock`; runs trusted lifecycle scripts and `patchedDependencies`. No native `.node` addons, and no git clones (other git hosts). |
| [Type checking, `bun check`, `bun fmt`](/compatibility/toolchain/) | ✅ Works | Completions, hovers and errors in the editor; `bun check` and `bun fmt` in the console. |
| [Frameworks](/compatibility/frameworks/) | ✅ Works | Elysia, Hono, Vite, Astro and Lit SSR, among others. |
| [Browsers](/compatibility/browsers/) | 🟡 Partial | Chrome and Edge 133+ and Firefox 134+ run code; Safari and iOS can edit but not run (no WebAssembly Memory64); Safari Technology Preview runs code. |

Try any of it on the [examples](/examples/) pages, which run when you press Run.

## How to read these pages


The playground runs your code in the browser's JavaScript engine, not in Bun. Bun's transpiler, resolver, semver and bundler run as WebAssembly. Everything else (`Bun.*`, `bun:*`, `node:*`) is a JavaScript shim, so coverage is uneven. These pages list what works today.

| Label | Meaning |
|---|---|
| ✅ Works | Behaves like Bun for normal use. |
| 🟡 Partial | The common parts work; the notes list what's missing. |
| ⚪ Stub | Imports fine, but its functions throw or do nothing. |
| ❌ Missing | Not available. Importing it fails, or the property is `undefined`. |
| ❔ Untested | Expected to work, but not checked yet. |
